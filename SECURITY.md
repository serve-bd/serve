# Security

Serve runs your apps, holds their secrets and controls Docker on your servers, so security
reports get priority.

## Report a problem

Report privately through [GitHub security advisories](https://github.com/serve-bd/serve/security/advisories/new).
Do not open a public issue, discussion or pull request for it.

Include what you found, how to reproduce it, the Serve version and what an attacker could do
with it. A proof of concept helps.

## What happens next

- You get an answer within 3 working days.
- The fix goes into a release as soon as it is ready. The release notes credit you, unless you
  ask not to be named.
- The advisory is published once a fixed release is out.

## Supported versions

Only the latest release gets security fixes. Serve updates itself from Settings → Updates.

## In scope

The dashboard, the worker, the API, the install script, the metrics agent and the published
image. Problems in an app you deploy with Serve belong to that app.
