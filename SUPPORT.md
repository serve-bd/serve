# Getting help

- **Documentation:** [serve.bd/docs](https://serve.bd/docs/) covers install, deploys, domains,
  databases, backups and updates.
- **Questions:** ask in [Discussions](https://github.com/serve-bd/serve/discussions). Search
  first: someone may have asked already.
- **Bugs:** open an [issue](https://github.com/serve-bd/serve/issues/new/choose) with the
  version, the steps and the logs.
- **Security problems:** report them privately, see [SECURITY.md](SECURITY.md).
